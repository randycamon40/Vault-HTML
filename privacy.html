Privacy Policy - HTML Vault Pro

Terakhir diperbarui: 19 Mei 2026

Ringkasan

HTML Vault Pro bekerja 100% offline. Semua file HTML, folder, dan log disimpan di IndexedDB perangkatmu. Kami tidak mengirim filemu ke server manapun.

Data yang Kami Kumpulkan

  • Tidak ada pelacakan, analytics, atau iklan pihak ketiga di dalam aplikasi.
  • File HTML tetap di browser kamu. Backup/Restore hanya terjadi jika kamu sendiri yang menekan tombol Export.

Penyimpanan

Data disimpan via IndexedDB dan localStorage. Menghapus data aplikasi di pengaturan browser akan menghapus semua vault.

Izin

Aplikasi hanya meminta izin penyimpanan lokal. Tidak ada akses kamera, lokasi, atau kontak.

Kontak

Jika ada pertanyaan: buat issue di GitHub repository proyek ini.
